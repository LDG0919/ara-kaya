데이터 삭제 안내

앱: 돈잡이 (Ledger) · 패키지: com.korea919.ledger
최종 업데이트: 2026년 6월 6일

돈잡이는 모든 데이터를 이용자 기기에 저장합니다. 이용자가 직접 언제든 아래 방법으로 삭제할 수 있습니다.

1. 기기 내 데이터 삭제

  • 개별 내역 삭제: 앱에서 해당 내역을 선택해 삭제합니다.
  • 전체 삭제: 앱을 삭제하거나, 안드로이드 설정 → 애플리케이션 → 돈잡이 → 저장공간 → 데이터 삭제를 실행합니다. 로컬에 저장된 모든 내역이 영구 삭제됩니다.

2. 광고 데이터

광고가 표시되는 경우, 광고는 Google AdMob이 제공합니다. 안드로이드 설정 → 개인정보 보호 → 광고(기기에 따라 명칭이 다를 수 있음)에서 광고 ID를 재설정하거나 제한할 수 있습니다.

3. 도움 요청

데이터 삭제에 도움이 필요하면 아래로 문의해 주세요. 합리적인 기간 내에 답변드립니다.
