데이터 삭제 안내

앱: 바람잡이 (Newsnote) · 패키지: com.korea919.news
최종 업데이트: 2026년 6월 6일

바람잡이는 데이터를 이용자 기기에 저장하며, 백업을 켠 경우 이용자 본인의 구글 드라이브에도 저장합니다. 모든 데이터는 이용자가 직접 관리하며 언제든 아래 방법으로 삭제할 수 있습니다.

1. 기기 내 데이터 삭제

  • 개별 스크랩 삭제: 스크랩을 길게 눌러 선택 모드로 들어가 삭제하거나, 스크랩을 열고 휴지통 아이콘을 누릅니다.
  • 전체 삭제: 앱을 삭제하거나, 안드로이드 설정 → 애플리케이션 → 바람잡이 → 저장공간 → 데이터 삭제를 실행합니다. 로컬에 저장된 모든 스크랩과 이미지가 영구 삭제됩니다.

2. 구글 드라이브 백업 삭제

드라이브 백업을 사용했다면 다음과 같이 삭제하세요.

  1. 사용한 계정으로 구글 드라이브에 접속합니다.
  2. "Newsnote" 폴더를 찾아 삭제하고, 휴지통을 비워 영구 삭제합니다.

3. 앱의 구글 계정 접근 권한 해제

  1. 앱의 사이드 메뉴에서 로그아웃을 누르거나,
  2. myaccount.google.com/permissions에서 Newsnote를 선택해 액세스 권한 삭제를 누릅니다.

4. 광고 데이터

광고는 Google AdMob이 제공합니다. 안드로이드 설정 → 개인정보 보호 → 광고(기기에 따라 명칭이 다를 수 있음)에서 광고 ID를 재설정하거나 제한할 수 있습니다.
